# Akhil Face ID - Release History & Updates

### 1.0.0 Production Release - 2026-11-15 (HP Victus Custom Build)

#### Highlights
- **Product Rebranding**: Complete transformation into **Akhil Face ID**, an exclusive, fully branded biometric security application.
- **Hardware Integration**: Custom tuning for HP Victus built-in HP Wide Vision HD Camera (`USB\VID_0408&PID_5482`).
- **Flexible Credential Pairing**: Seamless support for Windows 11 accounts configured with Windows Hello PIN or Microsoft Accounts. Stored securely inside the hardware TPM 2.0 chip with unverified fallback storage so setup is never blocked.
- **Low-Light Screen Flash Assist**: Intelligent illumination assist during facial enrollment: turns the laptop screen into a bright white illumination surface in low light, capturing clean facial landmark embeddings like smartphone selfie flashes.
- **Seamless Lock Screen Experience**: If recognized, Windows unlocks instantly without prompting for a password; if face recognition is paused or fails, your standard Windows PIN is immediately displayed.
- **Privacy & Offline Independence**: Standalone neural execution; removed external upstream polling; 100% offline biometric processing.
